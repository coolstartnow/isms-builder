# Kasutusjuhend: QMO / kvaliteedijuht

Kvaliteedijuht (QMO) koordineerib kvaliteedijuhtimissüsteemi (KJS) vastavalt ISO 9001-le või sektoripõhistele standarditele (IATF 16949, ISO 13485, AS9100) ning tagab lõimimise ISMS-iga.

---

| **Riskijuhtimine** | Riskid ISO 9001 punkti 6.1 järgi | Menüü: Riskid |
| **Juhtimine** | Juhtkonna ülevaatused (ISO 9001 punkt 9.3) | Menüü: Juhtimine |

| **Aruanded** | ISO 9001 vastavusmaatriks, ülevaatuse tsüklid | Menüü: Aruanded |

## Igapäevased ülesanded

### ISO 9001 meetmete haldamine
1. **SoA → vahekaart „ISO 9001“**
2. Hinda meetmeid praeguse rakendamise järgi (kohaldatav / osaliselt / ei kohaldu)
3. Põhipunktid: 4 (kontekst), 6.1 (riskid), 7 (tugi), 8 (tegevus), 9 (hindamine), 10 (parendamine)
4. Seo poliitikatega nupuga „🔗 Seosed“

### Kvaliteediriskide haldamine
1. **Riskid → Uus risk** — seo ISO 9001 meetmed nupuga „🔗 Seosed“
2. Kvaliteediga seotud riskid: tarnija tõrge, tootedefektid, pädevuse lüngad
3. Käsitlusabinõud: dokumenteeri FMEA tulemused tegevustena

### Kvaliteedieesmärkide jälgimine KPI-dega
1. **Eesmärgid → Uus eesmärk** (kehtib kõigile ISMS-i/KJS-i eesmärkidele)
2. Määra sihtväärtus, tegelik väärtus, ühik (%, arv, päevad) ja tähtaeg
3. Uuenda regulaarselt — edenemisriba näitab saavutust

### Juhtkonna ülevaatus (ISO 9001 punkt 9.3)
1. **Juhtimine → Juhtkonna ülevaatus → Uus ülevaatus**
2. ISO 9001 kohustuslikud teemad: kliendi tagasiside, auditi tulemused, eesmärkide olek, ressursid
3. Dokumenteeri otsused tegevuspunktidena (vastutaja + tähtaeg)
