# Kasutusjuhend: andmekaitsespetsialist

Andmekaitsespetsialist (DPO / GDPO) jälgib IKÜM-i ja sellega seotud andmekaitsenõuete täitmist.

> **Sõltumatus:** Andmekaitsespetsialist on oma ülesannete täitmisel juhistest vaba (IKÜM art 38 lg 3) ning teda ei tohi ülesannete täitmise pärast ametist vabastada ega karistada. Ta aruandleb otse kõrgeimale juhtkonnale.

## Igapäevased ülesanded

### Töötlemistoimingute registri pidamine
1. **Privaatsus → register → Uus kirje**
2. Kohustuslikud väljad: nimi, eesmärk, õiguslik alus (art 6/9), andmekategooriad, andmesubjektid, saajad, säilitustähtajad
3. Edastamine kolmandatesse riikidesse: sisesta riik + kaitsemeede (tüüplepingutingimused, siduvad kontsernisisesed eeskirjad)
4. CSV-eksport nupuga „CSV“ filtririba juures

### Mõjuhinnangu tegemine (IKÜM art 35)
1. **Privaatsus → mõjuhinnang → Uus hindamine**
2. Läviväärtuse kontroll: õiguste ja vabaduste riski hindamine
3. Dokumenteeri kavandatud abinõud ja jääkrisk
4. Olek: mustand → ülevaatusel → lõpetatud

### 72-tunnise rikkumisteate haldamine
1. Registreeri rikkumine jaotises **Privaatsus → intsidendid**
2. Süsteem käivitab 72 tunni loenduri registreerimisest automaatselt
3. Aegumisel: dokumenteeri asutuse teavitamine
4. Asutuse kontaktandmed jaotises **Seaded → andmekaitsespetsialist**

### Andmesubjekti taotluste menetlemine
1. **Privaatsus → taotlused → Uus taotlus**
2. Tähtaeg arvutatakse automaatselt andmekaitse seadete järgi (vaikimisi: 30 päeva, pikendatav 90-ni)
3. Olek: laekunud → töös → lõpetatud / tagasi lükatud
